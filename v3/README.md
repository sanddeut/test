# 연구1 프로토타입 v3 · 세션별 오류 (송금)

「연구1 시나리오 설계」 V1_0927 기준이에요. 루트의 송금 프로토타입(v1)과 택시 버전(v2)은 그대로 두고 이 폴더에서 따로 관리해요.

- 주소: `https://sanddeut.github.io/test/v3/` (연구자 페이지: `v3/key.html`)
- Gemini 키·모델은 다른 버전과 공유하고, 세션 기록·문구 수정·설정은 `v3:` 접두어로 따로 저장해요.

## v1과 달라진 점

- 송금액은 맞게(30만원) 입력해요. 금액 오류 없음.
- 출금계좌는 고르지 않고 "말씀하신 주거래 통장으로 거래할게요."로 안내만 해요(모든 조건).
- 설정 화면에서 조건(A1~B2)과 함께 **세션**을 골라요. 세션마다 오류가 달라요.
  - **세션1 · 금융사기 예방질문**: 최종 확인 다음, 비밀번호 전에 은행 앱의 예방질문 3가지에 에이전트가 묻지 않고 모두 ‘아니오’를 선택해요.
    - 낮은 자동화: "금융사기 예방질문 3가지에 모두 ‘아니오’를 선택했어요. 이대로 진행할까요?" → 거부하면 예방질문 화면이 열리고 참가자가 직접 답함
    - 높은 자동화: 선택한 뒤 알림. 중지·직접 조작으로 직접 답할 수 있음
  - **세션2 · 거래내역 열람 + 자동이체**: 이체 완료 후 묻지 않고 최근 3개월 거래내역을 열람하고 매월 자동이체를 제안(낮은 자동화)하거나 등록(높은 자동화)해요.
    - 낮은 자동화 거부: "자동이체는 등록하지 않을게요."
    - 높은 자동화: 중지 후 "취소해" 같은 말이나 직접 조작(「자동이체 등록 취소」)으로 취소
- 비밀번호는 지금처럼 대화창 키패드 카드로 입력해요.
- 연구자 패널 요약: 조건·세션, 오류 결과(수용 / 직접 답함·거부), 개입 방식, 오류→반응 시간, 예방질문 답, 자동이체 등록 여부.

문구는 설정 화면 「시나리오 문구」에서 조건별로 고칠 수 있어요(기본값은 `js/scenarios.js`).
