# 연구1 프로토타입 v2 · 택시 호출

루트의 송금 프로토타입은 그대로 두고, 과업을 **택시 호출**로 바꾼 버전이에요. 송금 버전의 원칙(2×2 조건, 에이전트 오류 1회, 낮은 자동화=단계별 승인 / 높은 자동화=안내 후 진행, 중지·직접 조작)과 화면 구성은 그대로예요.

- 주소: `https://sanddeut.github.io/test/v2/` (연구자 페이지: `v2/key.html`)
- 기존 버전과 같은 도메인이라 **Gemini 키·모델은 공유**돼요. 세션 기록·문구 수정·설정은 `v2:` 접두어로 따로 저장돼요.

## 과업

| | 상황 | 과업 |
|---|---|---|
| A | 오늘 저녁 7시 동창회 모임 장소는 ‘담소한정식 강남점’. 동천역으로 걸어가는 중이라 택시는 ‘신분당선 동천역’에서 타려고 함 | ① 출발지를 신분당선 동천역으로 바꾸기 ② 강남점으로 가는 택시 호출 |
| B | (A와 같음) + 정장이라 모범택시를 타려 하고, 요금은 기사님께 직접 내고, 할인 쿠폰도 쓰려고 함 | ① 출발지 바꾸기 ② 택시 호출 ③ 모범택시로 바꾸기 ④ 직접결제로 바꾸기 ⑤ 할인 쿠폰 적용 |

- **출발지**: 처음에는 휴대폰 GPS의 현재 위치예요(세션 시작 때 위치 권한을 물음, 거부하거나 실패하면 판교역 부근으로 대신 표시). A·B 모두 에이전트가 출발지를 ‘신분당선 동천역’으로 바꾸는 단계가 있어서, 바꾼 뒤에는 모든 참가자가 같은 거리·요금을 봐요. 연구 기록에는 정확한 좌표 없이 위치를 받았는지와 동네 이름만 남아요.
- **지도**: 실제 지도(Leaflet + 오픈스트리트맵/CARTO 타일, 키 필요 없음)와 실제 도로 경로(OSRM 공개 서버, 실패하면 점선 직선)를 보여줘요. 지도 라이브러리를 못 불러오면 그림 지도로 대체해요.
- **요금**: 거리 요금(기본 4,800원 + 1.6km 이후 km당 약 760원) × 택시 종류 배율(모범 1.6, 대형 1.9) − 쿠폰. 동천역에서의 거리는 고정값(강남점 21.2km, 강남구청점 23.5km, 역삼점 21.9km)이에요.
- 목적지는 A·B 모두 **검색**으로 찾아요. 에이전트는 ‘담소한정식 강남점’을 맞게 골라요(목적지 오류 없음).
- 기본값: 일반택시 · 자동결제(마음카드) · 쿠폰 적용 안 함 · 기사님 요청사항 없음. 쿠폰은 결제 방식과 상관없이 쓸 수 있어요.

## 세션별 오류 (설정 화면에서 세션 선택)

- **세션1 · 기사님 요청사항 임의 선택**: 최종 확인 다음, 호출 확인 화면의 [기사님 요청사항]에서 에이전트가 묻지 않고 ‘기사님과 이야기 나누며 가고 싶어요’를 골라요. 호출은 이 단계 뒤에 해요.
  - 모든 자동화 수준에서 요청사항 선택지 전체(없음·기사님과 이야기 나누며 가고 싶어요·조용히 가주세요·짐이 있어요·천천히 안전하게·빠른 길로)를 보여줘요. 진행 카드에는 목록(고른 항목에 체크), 실행화면에는 앱의 요청사항 바텀시트가 열린 채로 보여요.
  - 낮은 자동화: "기사님 요청사항으로 ‘기사님과 이야기 나누며 가고 싶어요’를 선택했어요. 이대로 호출할까요?" → 거부하면 "기사님 요청사항을 어떻게 할까요?"와 함께 선택지 목록 → 참가자가 누르거나 말한 항목으로 에이전트가 실행화면에서 다시 고른 뒤 승인을 다시 물음
  - 높은 자동화: 고른 뒤 알림(목록 함께 표시). 중지하면 선택지 목록과 [직접 조작]·[계속하기]가 함께 떠서 목록에서 바로 고를 수 있음(말하기·직접 조작도 가능)
- **세션2 · 이용내역 열람 + 예약 호출**: 호출 완료 후 묻지 않고 최근 3개월 이용내역(매주 토요일 담소한정식 강남점)을 열람하고, 다음 주 토요일(10월 10일) 오후 6시 20분 예약을 제안(낮은 자동화)하거나 등록(높은 자동화)해요.
  - 낮은 자동화 거부: "택시는 예약하지 않을게요." / 높은 자동화: 중지 후 "예약 취소해줘"나 직접 조작(「예약 취소」)으로 취소
- 연구자 패널 요약: 조건·세션, 오류 결과(수용 / 거부·수정), 개입 방식, 오류→반응 시간, 기사님 요청사항, 예약 여부.

## 단계

| # | 단계 | 조건 | 낮은 자동화 | 높은 자동화 |
|---|---|---|---|---|
| 1 | 택시 앱 실행 | 공통 | 택시 앱을 실행할까요? | 택시 앱을 실행할게요. |
| 1-1 | 출발지 변경 | 공통 | 출발지가 현재 위치로 되어 있어요. 출발지를 ‘신분당선 동천역’으로 바꿀까요? | 말씀하신 ‘신분당선 동천역’으로 출발지를 바꿨어요. |
| 2 | 목적지 설정 | 공통 | ‘담소한정식 강남점’을 찾았어요. 여기로 갈까요? | ‘담소한정식 강남점’을 목적지로 설정했어요. |
| 3 | 택시 종류 변경 | B | 택시 종류가 3개예요. 어떤 택시로 할까요? (일반/모범/대형) | 말씀하신 모범택시로 바꿨어요. |
| 4 | 결제 방식 | 공통 | 결제 방식이 2개예요. 어떻게 결제할까요? (자동/직접) | A: 자동결제(마음카드)로 결제할게요. / B: 말씀하신 직접결제로 바꿨어요. |
| 5 | 쿠폰 적용 | B | 쓸 수 있는 쿠폰이 있어요. ‘가을맞이 3,000원 할인 쿠폰’을 적용할까요? | ‘가을맞이 3,000원 할인 쿠폰’을 적용했어요. |
| 6 | 최종 호출 확인 | 공통 | 호출 내용을 최종 확인해주세요. | ‘{목적지}’으로 가는 {택시종류}를 호출할게요. |
| 6-1 | [세션1 오류] 기사님 요청사항 | 공통 | 기사님 요청사항으로 ‘기사님과 이야기 나누며 가고 싶어요’를 선택했어요. 이대로 호출할까요? | 기사님 요청사항으로 ‘기사님과 이야기 나누며 가고 싶어요’를 선택했어요. |
| 7 | 완료 | 공통 | {택시종류}를 호출했어요. 기사님이 3분 뒤 도착해요. | (같음) |
| 8 | [세션2 오류] 이용내역 열람 + 예약 호출 | 공통 | 최근 3개월 이용내역을 확인해 보니, 매주 토요일 담소한정식 강남점에 가신 기록이 있어요. 다음 주 토요일에도 같은 시간에 택시를 예약할까요? | … 같은 시간에 택시를 예약할게요. |

- 문구는 설정 화면 「시나리오 문구」에서 조건별로 고칠 수 있어요(`js/scenarios.js`가 기본값).
- 목적지·택시 종류·결제·쿠폰은 거부 후 말하기, 중지 후 말하기, 직접 조작(앱 화면에서 검색 결과·택시·결제·쿠폰을 누름)으로 바꿀 수 있어요.
- 연구자 패널 요약: 오류 결과(수용/정정/취소), 개입 방식, 오류→반응 시간, 최종 목적지, (B) 택시·결제·쿠폰.

## 파일

- `js/scenarios.js`: 과업·목적지·택시 종류·결제·쿠폰 데이터, 시나리오 문구, 단계 정의
- `js/phone.js`: 가상 택시 앱 「마음택시」 화면과 에이전트 조작 연출
- `js/app.js`: 진행 엔진(송금 버전과 같은 구조)
- `js/llm.js`: 택시 호출용 LLM 프롬프트·응답 형식·규칙 기반 대체
