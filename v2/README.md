- 주소: `https://sanddeut.github.io/test/v2/` (연구자 페이지: `v2/key.html`)
- 기존 버전과 같은 도메인이라 **Gemini 키·모델은 공유**돼요. 한쪽에서 저장하면 다른 쪽에서도 쓸 수 있어요.

- 화면 구성과 LLM 연결 방식은 루트 `README.md`와 같아요.
