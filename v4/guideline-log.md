# 연구2 개선안: 가이드라인 적용 기록

연구1에서 도출한 가이드라인(2안, 25개)을 택시 호출 프로토타입(v4)에 어떻게 적용했는지 기록해요.
수정할 때마다 이 파일도 함께 고쳐요. 프레임 번호는 개선안 페이지(연구2 프로토타입 개선안) 기준이고, 화면이 추가되면 바뀔 수 있어요.
번호는 FigJam '가이드라인 정리'의 2안(디자인 스페이스별 분류) 최신본 기준이에요. 1안(시간 순서) 번호는 4번 목록에 함께 적었어요.

## 1. 적용한 것

| 1 | 첫 화면은 입력 방법(상호작용 시작 방법)을 명시적으로 보여 줘야 한다. | 첫 화면에 긴 「눌러서 대화 시작」 버튼 하나만 두고, 누르면 「말로 하기」/「글로 하기」 두 버튼이 나타남. 첫 AI 말풍선 안에 안내 상자(ⓘ 이렇게 대화를 시작해보세요: ① 「눌러서 대화 시작」을 눌러요 ② 말로 할지, 글로 할지 골라요)를 넣고, 말로/글로를 고른 뒤에는 안내 상자를 숨김 | 0번 행 (대화 시작) |

| 25 | 시스템은 사용자가 대화나 익숙한 방식(취소, 뒤로 가기 등)으로도 작업을 통제할 수 있게 해야 한다. | 뒤로 가기를 누르면 진행을 멈추고 가운데 다이얼로그(딤 처리)를 띄움: "진행을 멈췄어요 / 어떻게 할까요?" + 계속하기, 방금 한 일 취소, 앱 종료. 앱 종료는 한 번 더 확인(앱을 종료할까요? 지금까지 한 일이 모두 취소돼요. / 종료하기, 돌아가기) | 뒤로 가기 행 |

## 4. 가이드라인 원문 (2안 최신본, 25개)

괄호 안은 1안(시간 순서) 번호예요.

**User query (사용자 입력)**

입력 방법
1. 첫 화면은 입력 방법(상호작용 시작 방법)을 명시적으로 보여 줘야 한다. (1안 1)

입력 피드백
2. 시스템은 사용자의 입력이 오류 없이 전달되었는지를 즉시 알려야 한다. (1안 14)
3. 시스템은 사용자의 요청이 수행되지 않았을 때 그 이유와 대안을 알려야 한다. (1안 24)
4. 시스템은 사용자가 알아야 할 내용을 놓치지 않도록 선제적으로 전해야 한다. (1안 15)
5. AI는 사용자의 입력을 실행하기 전에, 무엇을 하려는지 먼저 알려야 한다. (1안 16)

**Explainability of agent activities (에이전트 활동 설명)**

주체 구분
6. 화면은 지금 AI와 사용자 중 조작권이 누구에게 있는지 보여 줘야 한다. (1안 4)
7. 화면은 AI가 대신 정한 내용을 사용자가 한 것과 구분되도록 분명히 표시해야 한다. (1안 6)

진행 현황
8. 화면은 지금 진행 중인 단계가 무엇인지 분명히 알려야 한다. (1안 2)
9. 화면은 사용자가 지금 행동해야 하는지 기다려야 하는지를 명확히 보여 줘야 한다. (1안 3)

정보 제시
10. 화면은 핵심 정보만 간결하게 보여 주고, 부가 정보는 사용자가 원할 때 확인할 수 있게 해야 한다. (1안 7)
11. 시스템은 사용자가 읽고 확인할 시간을 충분히 제공해야 한다. (1안 8)

**User control (사용자 통제)**

중지 수단
12. 화면은 중지 수단의 위치와 기능을 한눈에 알아볼 수 있게 보여 줘야 한다. (1안 10)

실행 중 개입
13. 화면은 사용자가 AI로부터 조작권을 언제든 회수할 수 있음을 드러내야 한다. (1안 11)
14. 시스템은 결과가 확정되기 전에 사용자가 개입할 시점을 보장해야 한다. (1안 12)

수정과 되돌리기
15. 시스템은 사용자가 AI의 결정을 수정하는 방법을 알고 쉽게 수정할 수 있도록 해야 한다. (1안 22)
16. 시스템은 결과가 확정된 뒤에도 사용자가 되돌릴 수 있게 해야 한다. (1안 23)

승인과 위임 범위
17. 시스템은 AI의 제안을 사용자가 쉽게 거절할 수 있게 해야 한다. (1안 18)
18. AI는 비가역적이거나 요청 외의 행동은 반드시 실행 전에 확인을 받고, 사소한 단계의 확인은 줄여야 한다. (1안 19)
19. AI는 결정의 중요도에 맞는 표현으로 확인을 요청해야 한다. (1안 20)
20. AI는 사용자의 선호가 필요한 결정을 임의로 내리지 않고, 사용자에게 먼저 물어야 한다. (1안 17)

정보 접근
21. AI는 어떤 정보에 접근해 무엇에 쓰는지 투명하게 공개해야 한다. (1안 21)
22. 시스템은 사용자가 AI의 정보 접근을 제한하거나 기록을 지울 수 있게 해야 한다. (1안 25)

**User mental model & expectations (사용자 멘탈모델/기대)**

화면 이해
23. 화면은 실행 화면이 AI가 지금 내 앱을 대리조작하는 실시간 화면임을 명시적으로 알려야 한다. (1안 5)
24. 화면의 누를 수 있는 요소와 없는 요소는 명확히 구분되어야 한다. (1안 9)

기대에 맞는 통제 방식
25. 시스템은 사용자가 대화나 익숙한 방식(취소, 뒤로 가기 등)으로도 작업을 통제할 수 있게 해야 한다. (1안 13)
