# 연구1 · 송금 에이전트 시나리오 프로토타입

「연구1 시나리오 설계」의 2×2 조건(복잡도 A/B × 자동화 낮음/높음)을 참가자가 직접 체험하는 웹 프로토타입이에요.
참가자는 폰 화면 속 AI 도우미에게 말(글·음성)로 송금을 요청하고, 에이전트는 **30만원을 10만원으로 잘못 알아듣는 오류 1회**를 포함한 스크립트대로 진행해요.

## 실행

빌드나 설치가 필요 없어요. 정적 파일이라 아무 웹서버로 열면 돼요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

GitHub Pages에 올려도 그대로 동작해요.

## LLM (Gemini) 연결

- 설정 화면에 **Gemini API 키**를 넣고 「연결 테스트」를 눌러 확인해요. 「모델 목록」으로 쓸 수 있는 모델을 불러와 고를 수 있어요. 기본값은 `gemini-2.5-flash`예요.
- 키는 브라우저에서 Google API로 바로 전송돼요. 「이 브라우저에 키 저장」을 켜면 localStorage에만 저장돼요. 공용 PC라면 끄세요.
- **LLM은 참가자 발화 해석에만 써요.** 에이전트 문구와 순서는 `js/scenarios.js` 스크립트로 고정돼 있어서 조건 간 문구·정보량이 똑같이 유지돼요.
  - 첫 과업 요청 해석 (금액·계좌·메모 추출, 송금 요청이 아니면 되묻기)
  - 선택지 질문에 대한 자유 발화 해석 (“네 맞아요” → 승인, “주거래 통장” → 주거래)
  - 거부·중지 후 “어떻게 바꿀까요?”에 대한 답 해석 (“삼십만원이요” → 금액 300,000원으로 변경)
- 키가 없거나 호출이 실패하면 **규칙 기반 해석**으로 자동 전환되고, 로그에 기록돼요.

## 조건별 동작

| | 낮은 자동화 (A1, B1) | 높은 자동화 (A2, B2) |
|---|---|---|
| 진행 | 판단 지점마다 승인 요청 (A 5회, B 6회) | 승인 없이 자동 진행 (단계 간격은 설정에서 조절) |
| 오류 대응 | 「거부」 → “어떻게 바꿀까요?” → 수정 금액 확인 | 「■ 중지」 또는 말 걸기 → “진행을 멈췄어요. 어떻게 바꿀까요?” / 「✋ 직접조작」 → 화면에서 직접 수정 |
| 직접조작 | 이체 직전 계좌 비밀번호 4자리 직접 입력 (모든 조건 공통) | |

높은 복잡도(B)는 문자 앱에서 총무 문자를 찾아 계좌를 복사하는 단계와 ‘30기 {이름}’ 메모 단계가 추가돼요.

## 연구자 패널 (우측 상단 버튼 또는 Ctrl + .)

- 진행 단계, 실시간 이벤트 로그 (에이전트 발화, 참가자 입력, LLM 해석 결과와 지연 시간)
- 요약 지표: 오류 결과(수용/수정/취소), 개입 방식, **오류 문구 노출 → 반응까지 걸린 시간**, 최종 금액, 승인 응답 수, 중지·직접조작 횟수
- 내보내기: 이 세션 JSON, 이벤트 CSV, 이 브라우저에서 진행한 전체 세션 요약 CSV (엑셀에서 한글이 깨지지 않게 BOM 포함)

## 파일 구조

```
index.html        설정 화면 · 실험 화면 · 연구자 패널
css/style.css
js/scenarios.js   조건·상황·에이전트 문구 (문구 수정은 여기서)
js/llm.js         Gemini 호출 + 규칙 기반 해석
js/app.js         진행 엔진, 폰 화면 렌더링, 로그
```
