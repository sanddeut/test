# 연구1 · 송금 에이전트 시나리오 프로토타입

「연구1 시나리오 설계」의 2×2 조건(복잡도 A/B × 자동화 낮음/높음)을 참가자가 직접 체험하는 웹 프로토타입이에요.
참가자는 폰 화면 속 AI 도우미에게 말(글·음성)로 송금을 요청하고, 에이전트는 **30만원을 10만원으로 잘못 알아듣는 오류 1회**를 포함한 스크립트대로 진행해요.

## 실행

빌드나 설치가 필요 없어요. 정적 파일이라 아무 웹서버로 열면 돼요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

GitHub Pages에 올려도 그대로 동작해요.

## LLM (Gemini) 연결

- 설정 화면에 **Gemini API 키**를 넣고 「연결 테스트」를 눌러 확인해요. 「모델 목록」으로 쓸 수 있는 모델을 불러와 고를 수 있어요. 기본값은 `gemini-3.5-flash`예요. 응답 속도를 위해 추론 수준(`thinkingLevel`)을 `minimal`로 두고, 모델이 이 설정을 지원하지 않으면 설정 없이 다시 요청해요.
- 키는 브라우저에서 Google API로 바로 전송돼요. 「이 브라우저에 키 저장」을 켜면 localStorage에만 저장돼요. 공용 PC라면 끄세요.
- **고정 문구는 스크립트, 스크립트 밖 응답은 LLM**이 만들어요. 에이전트의 정해진 문구와 순서는 `js/scenarios.js`에 고정돼 있어요. LLM은 참가자 발화마다 다음 일을 해요.
  - 의도 분류와 값 추출: 승인·거부, 금액(“삼십만원” → 300,000), 메모, 출금계좌, 계좌번호
  - 예상 밖의 말(질문, 잡담, 금액 외 수정 요청)에는 해요체 2문장 이내로 자연스럽게 답하고, 강압적이지 않게 현재 단계로 돌아오게 해요.
- 키가 없거나 호출이 실패하면 **규칙 기반**으로 전환돼요. 답변을 유형별로 나눠 정해진 문구로 응답하고, 전환된 사실은 로그에 남아요.

## 조건별 동작 (수정본 기준)

| | 낮은 자동화 (A1, B1) | 높은 자동화 (A2, B2) |
|---|---|---|
| 진행 | 판단 지점마다 승인 요청 | 승인 없이 자동 진행 (단계 간격은 설정에서 조절) |
| 오류 대응 | 「거부」 → “무엇을 수정할까요?”(A) / “어떻게 바꿀까요?”(B) → 수정 금액 확인 | 「■ 중지」 또는 말 걸기 → “진행을 멈췄어요. 어떻게 바꿀까요?” / 「✋ 직접조작」 → 화면에서 직접 수정 |
| 비밀번호 | 이체 직전 계좌 비밀번호 4자리 직접 입력 (모든 조건 공통) | |

- 광고 팝업은 **높은 복잡도(B)에서만** 떠요.
- B는 문자 앱에서 총무 문자를 찾아 계좌를 복사하는 단계와 ‘30기 {이름}’ 메모 단계가 추가돼요.

낮은 자동화에서 「거부」를 누르면 단계별로 이렇게 처리해요.

| 단계 | 거부 후 |
|---|---|
| 앱 실행 | “어떤 앱으로 실행할까요?” → 어떤 앱을 말해도 정해진 프로토타입 실행 |
| 받는 계좌 / 문자 속 계좌 | “어떤 계좌로 송금할까요?” → 다른 계좌를 찾아달라고 하면 같은 계좌를 다시 제시, 계좌번호를 말하면 그 계좌로 입력 |
| 광고 팝업 | LLM이 상황에 맞게 응답 (예: “알겠어요. 팝업 내용을 보시고 직접 닫으시면 이어서 진행할게요.”) → 참가자가 폰 화면에서 직접 닫으면 진행 |
| 송금액 (오류) | 금액을 말하면 “송금액 30만원을 입력할까요?”로 확인, 금액 외 요청이면 LLM이 응답하고 흐름으로 복귀 |
| 메모 | “어떻게 메모를 남길까요?” → 말한 문구로 다시 확인 |
| 최종 확인 | “무엇을 수정할까요?” → 금액·출금계좌·메모 수정 후 다시 확인, 그 외 요청이면 LLM이 응답하고 흐름으로 복귀 |

## 연구자 패널 (우측 상단 버튼 또는 Ctrl + .)

- 진행 단계, 실시간 이벤트 로그 (에이전트 발화, 참가자 입력, LLM 해석 결과와 지연 시간)
- 요약 지표: 오류 결과(최종 이체 금액 기준 수용/수정/취소, 송금액 단계에서의 결정은 `amount_step_decision`), 개입 방식, **오류 문구 노출 → 반응까지 걸린 시간**, 최종 금액, 승인 응답 수, 중지·직접조작 횟수
- 내보내기: 이 세션 JSON, 이벤트 CSV, 이 브라우저에서 진행한 전체 세션 요약 CSV (엑셀에서 한글이 깨지지 않게 BOM 포함)

## 파일 구조

```
index.html        설정 화면 · 실험 화면 · 연구자 패널
css/style.css
js/scenarios.js   조건·상황·에이전트 문구 (문구 수정은 여기서)
js/llm.js         Gemini 호출 + 규칙 기반 해석
js/app.js         진행 엔진, 폰 화면 렌더링, 로그
```
